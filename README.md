# FNCTN

FNCTN is a digital sports tournament platform for Egyptian university athletics, fan engagement, and tournament management.

- **[Frontend](file:///c:/Users/user/Desktop/Freelancing/FNCTN/FNCTN/Frontend)**: React 19 + TypeScript + Vite 8 + Tailwind CSS v4 web application.
  - **[Frontend Run & Deployment Guide](file:///c:/Users/user/Desktop/Freelancing/FNCTN/FNCTN/Frontend/RUN_AND_DEPLOYMENT_GUIDE.md)**: Instructions to run locally and deployment strategies.
  - **[Frontend Architecture Documentation](file:///c:/Users/user/Desktop/Freelancing/FNCTN/FNCTN/Frontend/fnctn_frontend_architecture.md)**: Page structure and routing.
- **[Backend](file:///c:/Users/user/Desktop/Freelancing/FNCTN/FNCTN/Backend)**: FastAPI backend service.
  - **[Backend Architecture](file:///c:/Users/user/Desktop/Freelancing/FNCTN/FNCTN/Backend/ARCHITECTURE.md)**: FastAPI data models and architecture.
- **[Docs](file:///c:/Users/user/Desktop/Freelancing/FNCTN/FNCTN/Docs)**: Technical and functional specifications.

## Quick Start (Frontend)

```powershell
cd Frontend
pnpm install
pnpm run dev
```

The app will run at **http://localhost:8443**.
